# Black Launcher — лаунчер Minecraft для Android

Тёмный минималистичный лаунчер на **Kotlin + Jetpack Compose**. Все инструменты бесплатные.

Все вкладки в одном интерфейсе: Главная, Косметика, Профиль, Друзья, Чат, Магазин, Настройки, О лаунчере.
Навигация: боковое меню (☰) со всеми вкладками и нижняя панель с основными.

## Что работает по-настоящему

| Функция | Как работает |
|---|---|
| Выбор версии | Список версий загружается с серверов Mojang (релизы, снапшоты, бета/альфа), кэшируется для работы без сети |
| Кнопка «Играть» | Скачивает описание версии и `client.jar` с Mojang, показывает прогресс, проверяет SHA-1 |
| Авторизация | Вход по нику (офлайн-режим), проверка ника в Mojang, UUID |
| Косметика | 12 скинов, 8 плащей, 8 крыльев, 10 аксессуаров. Персонаж рисуется кодом, можно примерять и надевать |
| Магазин | Покупки за монеты и кристаллы, ежедневный бонус, обмен монет на кристаллы |
| Профиль | Ник, UUID, статистика, смена ника, голова скина |
| Друзья и чат | Список друзей и переписка, хранятся на устройстве |
| Настройки | ОЗУ (слайдер), аргументы JVM, снапшоты/старые версии, очистка файлов, полный сброс |

## Честные ограничения

1. **Игра внутри этого приложения не запускается.** Minecraft: Java Edition на Android требует
   среду Java и трансляцию OpenGL — это огромная отдельная задача, её решает **PojavLauncher**.
   После подготовки версии кнопка «Играть» предлагает открыть установленный PojavLauncher
   (или Minecraft Bedrock, если он есть).
2. **Косметика видна только в лаунчере.** В самой игре скины/крылья/плащи не появятся без серверной
   или модовой поддержки.
3. **Друзья и чат локальные.** Три друга при первом запуске — демо. Для настоящего онлайна нужен
   сервер (см. ниже).
4. **Вход через Microsoft не реализован.** Есть только офлайн-вход по нику.
5. **Реальных платежей нет.** Валюта зарабатывается в приложении.
6. Проект написан без возможности собрать его в среде разработки. Версии библиотек подобраны
   под стабильные, но при первой сборке возможны мелкие правки. Если Gradle или Android Studio
   покажет ошибку, пришлите текст — исправим.

## Как получить APK и установить на телефон

### Способ 1. Android Studio (на компьютере)

1. Установите [Android Studio](https://developer.android.com/studio) (бесплатно).
2. `File → Open` и выберите папку `BlackLauncher`.
3. Дождитесь загрузки Gradle 8.9 и зависимостей (нужен интернет, 5–10 минут).
4. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
5. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

### Способ 2. GitHub Actions (без установки программ)

1. Создайте бесплатный аккаунт на github.com и новый репозиторий.
2. Загрузите в него содержимое папки `BlackLauncher` (в браузере на компьютере можно перетащить
   файлы и папки, включая скрытую `.github`).
3. Откройте вкладку **Actions → Build APK → Run workflow**.
4. Через несколько минут скачайте `BlackLauncher-debug-apk` из раздела **Artifacts** и распакуйте ZIP.

### Установка на телефон

1. Перенесите `app-debug.apk` на телефон.
2. Откройте файл. Android попросит разрешить установку из этого источника — разрешите.
3. Запустите «Black Launcher», введите ник, выберите версию.

### Чтобы реально поиграть

1. Установите **PojavLauncher** (F-Droid или GitHub-релизы проекта).
2. В Black Launcher выберите версию и нажмите «Играть». Когда версия подготовится,
   нажмите «Открыть PojavLauncher» и выберите ту же версию там.

```

├── MainActivity.kt

    ├── ProfileScreen.kt, SocialScreens.kt, SettingsScreen.kt, LoginScreen.kt
```

## Как развивать дальше

- **Настоящие друзья и чат.** Бесплатные варианты: Firebase (Auth + Firestore) или Supabase.
  Логику нужно заменить в `LauncherViewModel` (`friends`, `chats`, `sendMessage`).
- **Скины как PNG.** Мини-превью можно заменить на загрузку текстуры 64×64 из Mojang или из галереи.
- **Вход через Microsoft.** Официальная цепочка: Microsoft OAuth → Xbox Live → XSTS → Minecraft Services.
  Для неё нужно зарегистрировать приложение в Azure.
- **Новый предмет косметики.** Добавьте строку в `Catalog.kt`, и он появится в косметике и магазине.
